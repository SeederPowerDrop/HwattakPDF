# PDF Viewer & Editor App Icon Concepts

Generated as three independent bitmap concepts with OpenAI ImageGen. The design brief intentionally excludes free, donation, price, paywall, coin, ribbon, and subscription imagery. Green is excluded from the palette.

## A — Read & Mark

```text
Create a premium macOS app icon for a local PDF viewer and editor. Transparent outer canvas. A large midnight-navy rounded-square base with restrained soft 3D depth. Center one warm-ivory PDF document with a subtle folded top-right corner, a few bold charcoal document lines, one muted-blue selected/highlighted line, and a confident coral-red fountain-pen nib making a short edit mark. The page must resemble a real academic paper or contract, not a blank generic file. Clean geometric forms, crisp silhouette, balanced spacing, native macOS quality, readable at 32 px. No letters, no PDF text, no green, no price/free/donation/subscription/paywall symbols, no coins, no ribbons, no Adobe logo, no tiny UI tiles, no photorealism. Square 1:1 composition.
```

Asset: `Resources/AppIcon-Concept-A-ReadMark.png`

## B — Page Stack

```text
Create a premium macOS app icon for a multipage PDF viewer, organizer, and editor. Transparent outer canvas. A large graphite-to-deep-navy rounded-square base with subtle soft 3D depth. Show three slightly staggered warm-ivory document pages as a compact stack. The front page resembles a contract or technical document with a strong heading line, body lines, and a simple table. Overlay one clean muted-blue selection frame with a small coral-red resize handle to communicate editable PDF content. Elegant, minimal, professional, crisp three-mass silhouette, native macOS quality, readable at 32 px. No letters, no PDF text, no green, no price/free/donation/subscription/paywall symbols, no coins, no ribbons, no Adobe logo, no feature-grid dashboard, no photorealism. Square 1:1 composition.
```

Asset: `Resources/AppIcon-Concept-B-PageStack.png`

## C — Split Workspace

```text
Create a premium macOS app icon for reading and editing substantial PDFs such as textbooks, research papers, and contracts. Transparent outer canvas. A large warm-stone/ivory rounded-square base with a deep-ink inner frame. Inside, show a clean two-page split-view workspace: the left page has academic text, a small chart, and a muted-blue highlight; the right page has contract-like paragraphs, a compact table, and a signature line. Add two restrained coral-red text-edit carets to signal editing. Minimal geometric forms, low detail, balanced symmetry, subtle soft depth, native macOS quality, readable at 32 px. No letters, no PDF text, no green, no price/free/donation/subscription/paywall symbols, no coins, no ribbons, no Adobe logo, no photorealism. Square 1:1 composition.
```

Asset: `Resources/AppIcon-Concept-C-SplitWorkspace.png`

## Output notes

- Final assets are 1024 × 1024 PNGs with alpha transparency.
- Magenta chroma-key generation backgrounds were removed with the ImageGen skill helper before export.
- All three concepts were checked at 128 px and 32 px.
- These are exploration assets only; the app build still uses the previously selected icon until one concept is approved.
