# 학습 교재와 주석 검증 기록

2026-09-30에 진행한 교재 작업의 확인 범위입니다. 앱 전체의 새 릴리스(release) 검증과 구분합니다.

## 코드 변경

최초 교재 작업에서 앱 소스 8개에 한국어 학습 주석 80줄을 추가했습니다. 작업 시작 시 복사한 파일과 비교했을 때 삭제한 줄과 주석 외에 추가·변경한 실행 문장은 없었습니다. 기존에 커밋(commit)하지 않은 변경도 유지했습니다. Rust 코드는 `Examples/Learning/RustPageSelection`에 있는 독립 실습으로, Swift 앱의 빌드(build)나 실행 과정에 연결하지 않았습니다.

## 최초 교재 작업에서 실행한 검사

| 항목 | 결과 | 범위 |
| --- | --- | --- |
| Swift 빌드 및 선택 테스트 | 78개 통과, 실패 0 | OCRPageSelectionTests, PDFEditHistoryTests, PDFExternalModificationConflictTests, PDFWorkspaceModeTests |
| Rust 단위 테스트 | 12개 통과 | 페이지 선택·범위·오류·중복·표시 문자열 |
| Rust 문서 테스트 | 1개 통과 | 함수 설명의 실행 예제 |
| Rust 명령행 실행 | 정상·오류 출력 확인 | 기본 입력, 범위 기호, 연습 입력, 범위 초과 오류와 종료 코드 |
| 프로젝트 정적 검사 | 통과 | 0.9.0 build 20, 리소스·설정, 10개 언어 키 일치 |
| 변경 공백 검사 | 통과 | `git diff --check` |

첫 Swift 빌드는 같은 작업 폴더에서 별도로 진행 중이던 `PageTranslationExporter.swift`가 빌드 중 바뀌어 중단됐습니다. 당시 소스를 작업 전용 폴더에 복사해 고정한 뒤 다시 빌드했고, 위 78개 검사가 통과했습니다. 따라서 이 결과는 그 시점의 소스 사본인 스냅샷(snapshot)을 대상으로 합니다. 이후 별도 작업에서 바뀐 코드까지 검증한 결과는 아닙니다. 전체 배치 테스트(batch test)나 설치 앱의 화면 조작은 이번 주석 작업에서 다시 실행하지 않았습니다.

검증 환경은 macOS arm64, Apple Swift 6.2.4, Rust 1.94.0과 Cargo 1.94.0입니다. 실행 기록과 소스 비교 자료는 로컬 `work/learning-2026-09-30`에 있습니다. 이 폴더는 저장소의 기존 정책에 따라 Git에서 제외됩니다.

## 교재 내용과 판본

실제 함수와 호출 경로, 현재 OCR 부분 적용·페이지 보존, 저장 시 직접 쓰기를 사용하는 호환 경로(fallback), 실행 취소(undo) 실패 처리 등을 원문과 대조했습니다. 수록한 코드가 실제 발췌인지, 축약인지, 독립 예제인지 설명했습니다. Rust 예제는 Swift와 모든 동작이 일치하는 구현이나 앱에 통합한 코드로 표현하지 않았습니다.

PDF는 한글 글꼴을 포함하고 목차·북마크(bookmark)·검색 가능한 텍스트로 제작했습니다. 페이지를 이미지로 렌더링(rendering)해 코드·표·한글 표시와 페이지 나눔을 검토했습니다. PDF를 다른 폴더로 옮기거나 뷰어가 로컬 파일 링크를 차단하면 코드 링크를 직접 열지 못할 수 있으므로 Markdown 원문의 상대 링크도 제공합니다.

브라우저 판본은 외부 서버나 외부 자바스크립트 없이 읽는 HTML입니다. 로컬 파일을 여는 브라우저 자동화는 도구의 URL 보안 정책으로 차단되어 실제 브라우저 화면과 검색 조작은 확인하지 못했습니다. 파일 구조·코드 문법·장 이동 대상과 로컬 링크를 정적으로 확인했습니다. 최초 판본에서는 Markdown 로컬 링크 95개와 HTML 링크 125개의 대상이 유효했습니다.

## 원어 병기와 한국어 교정

최초 교재를 만든 뒤 사용자의 요청에 따라 안내문과 1~7장, Rust 실습 안내, 학습용 코드 주석을 다시 읽었습니다. 전문 용어는 각 장의 첫 설명에서 한국어와 원어를 괄호로 함께 적고, 번역투와 어색한 영어 혼용을 다듬었습니다. 설명 문체는 “합니다/입니다”로 통일했으며, 용어 표를 확장했습니다. 코드와 대조하면서 현재 페이지 인덱스를 그대로 사용하는 처리와 `private(set)`의 접근 제한 설명도 더 정확하게 고쳤습니다.

이번 교정에서 확인한 범위는 다음과 같습니다.

- 교재와 Rust 안내의 코드 블록 61개를 교정 전 사본과 비교해 그대로임을 확인했습니다.
- Swift 소스 8개는 학습 주석만 수정했으며 실행 코드와 다른 기존 주석은 유지했습니다. Rust 소스 2개도 주석만 수정했고 실행 코드·문서 테스트 코드·라이선스는 유지했습니다.
- 앱의 기능을 바꾸지 않았으므로 위의 Swift·Rust 동작 테스트를 이번 문장 교정에서 다시 실행하지는 않았습니다.
- 수정된 PDF는 59쪽이며 목차 북마크 8개와 검색 가능한 한글·영문 텍스트를 확인했습니다. 전체 페이지를 이미지로 확인하고, 원어가 긴 용어 표와 Rust 비교표도 확대해 검토했습니다.
- Markdown 로컬 링크 95개와 HTML 링크 125개의 대상, HTML의 장 제목 8개, 포함된 자바스크립트의 문법을 확인했습니다. 변환 과정에서 강조 표시가 별표로 남은 부분도 수정했습니다.
- 브라우저 판본의 실제 화면 조작은 앞서 기록한 도구 제한으로 확인하지 못했습니다. 이번에도 파일과 코드의 정적 검사만 수행했습니다.

교정 전 사본과 확인 결과는 로컬 `work/learning-language-review`에 있습니다.

## 초보자를 위한 기초 내용 보강

사용자의 추가 요청에 따라 0장을 신설하고, 기존 장 앞에 쉬운 예제와 첫 독서 순서를 보강했습니다. 변수·대입·타입·조건·반복·배열·함수·주석·터미널부터 설명합니다. Swift와 Rust에는 실제 앱이나 PDF 파일을 건드리지 않는 첫 실습을 각각 추가했습니다. 기존 용어의 원어 병기와 한국어 문체는 유지했습니다.

이번에 실행한 확인은 다음과 같습니다.

| 대상 | 확인 결과 |
| --- | --- |
| 0장의 독립 Swift 예제 9개 | 각각 실행해 예상 출력과 일치함을 확인 |
| 6장의 테스트 입문 예제 1개 | 실행 결과가 예상한 `true`임을 확인 |
| Swift 첫 실습 | 기본 실행의 출력 5줄이 안내와 일치 |
| Rust 첫 실습 | 기본 실행의 출력 4줄이 안내와 일치 |
| Rust의 숫자 바꾸기 연습 | 별도 사본에서 5쪽 허용·0쪽 거절 출력을 확인 |
| 기존 코드 발췌 보존 | 기존 코드 블록 61개를 유지하고 새 설명과 예제를 추가 |
| 기존 Rust 구현 보존 | `src/main.rs`·`src/lib.rs`가 보강 전 사본과 동일 |

Swift 실행 검증에는 6.2.4 도구를 사용했습니다. 실행 환경에서 기본 캐시(cache) 폴더의 쓰기를 제한하여, 검증할 때만 `-module-cache-path`로 임시 폴더를 지정했습니다. 이 설정은 코드를 바꾸지 않습니다. 새 실습은 기존 앱의 빌드 대상에 추가하지 않았으며, 앱 전체 테스트를 다시 실행한 결과로 해석해서는 안 됩니다.

최종 PDF는 73쪽이며 안내문과 0~7장에 대응하는 북마크 9개를 제공합니다. 전체 페이지와 긴 표·명령의 줄바꿈을 시각적으로 검토했습니다. Markdown 로컬 링크 122개, HTML 링크 147개, HTML 장 제목 9개를 확인했고, 브라우저 판본에 포함된 자바스크립트의 문법도 검사했습니다. 브라우저 화면 조작은 앞서 기록한 도구 제한으로 확인하지 못했습니다.

이번 보강의 원고 사본, 새 예제의 실행 기록, PDF 검토 자료는 로컬 `work/learning-beginner`에 있습니다. 이 폴더는 기존 저장소 정책에 따라 Git에서 제외됩니다.

## 학습할 때의 구분

테스트 통과는 검사한 입력과 조건에서 기대한 결과가 나왔다는 뜻입니다. 모든 PDF의 보존, 모든 OCR 인식 정확도, 성능 또는 실제 앱 화면의 완전함까지 입증하지는 않습니다. 교재를 따라 새 코드를 작성했다면 바꾼 부분의 기대 결과를 적고 관련 테스트를 다시 실행해 보세요.
