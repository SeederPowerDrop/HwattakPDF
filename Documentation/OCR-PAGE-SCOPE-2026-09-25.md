# OCR 페이지 선택과 안내 문구 개선 — 2026-09-25

## 사용자 동작

OCR 창에서 전체 페이지, 현재 페이지, 직접 지정을 선택한다. 직접 지정에는 `1, 3-5, 8`처럼 한 페이지와 연속 범위를 함께 입력할 수 있다. 페이지 번호는 책에 인쇄된 쪽수가 아니라 뷰어 상단에 표시된 PDF 페이지 순서다. 잘못된 번호, 빈 입력, 역순 범위, 문서 밖 번호는 실행 전에 안내한다.

시작 시 선택한 범위를 확정하며, 진행률은 선택한 페이지 수를 기준으로 표시한다. 완료 후 범위를 바꾸면 새 범위로 OCR을 실행해야 결과를 적용하거나 저장할 수 있다. 현재 PDF에 적용과 새 PDF로 저장 모두 문서 전체를 유지하면서 선택한 페이지에만 결과를 반영한다.

## 설명 문구

- 제목: 이 Mac에서만 처리합니다
- 설명: 파일을 외부로 보내지 않습니다. 중단해도 이어서 할 수 있도록 진행 내용을 이 Mac에 저장합니다.
- 결과 안내: OCR을 적용한 페이지의 메모는 따로 수정할 수 없고, 링크와 입력 칸은 작동하지 않습니다.

보관 내용과 이미지 변환 설명은 펼쳐 보는 항목에 넣었다. ‘Application Support’, ‘체크포인트’, ‘평탄화’ 같은 구현 용어를 기본 안내에서 제거했다. 이전 화면의 한국어 원문 키도 새 문구로 연결했고, 10개 언어의 키와 형식 인수를 일치시켰다.

## 적용과 저장

- 인식 설정은 선택한 원본 페이지 인덱스를 포함하며, 범위별로 중단·재개 결과를 구분한다.
- 인식 결과가 해당 범위를 정확히 포함해야만 적용·저장이 가능하다. 누락된 페이지나 범위 밖 결과를 함께 적용하지 않는다.
- 새 인식 결과가 있는 페이지만 다시 그린다. 선택하지 않은 페이지와 건너뛰었거나 새 글자를 찾지 못한 페이지의 텍스트·주석·입력 양식·자르기·회전을 보존한다.
- 선택하지 않은 페이지의 내부 링크가 교체된 페이지를 가리키면 새 페이지로 연결하고, 실행 취소 시 원래 대상으로 되돌린다. 목차의 위치와 확대 비율도 유지한다.
- 현재 문서에서는 바뀌지 않은 페이지 객체도 유지하며, 적용은 실행 취소·다시 실행할 수 있다. 새 결과가 전혀 없으면 수정 사항을 만들지 않는다.
- 비동기 저장, 선택 파일에만 쓰기 권한이 있는 경우의 저장, 원본 경로 보호와 저장 도중 외부 변경 검사를 유지한다.

## 검증

페이지 범위 파싱과 실제 인식 서비스의 선택 페이지 처리·재개, 현재 페이지 진행 번호, 선택 범위의 적용·전체 PDF 저장, 잘못된 결과 차단, 원본 유지, 실행 취소·다시 실행을 검사했다. 부분 내보내기에서는 입력 양식과 외부·내부 링크, 목차 위치·확대 비율을 확인했다.
