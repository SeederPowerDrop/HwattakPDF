> **2026-10-01 소스 통합 안내:** 아래 본문은 9월 25일 최초 작업 당시의 기록입니다. 이후 [페이지 선택과 부분 적용 개선](OCR-PAGE-SCOPE-2026-09-25.md)에 따라 기본 저장 이름은 소문자 `원본이름-ocr.pdf`로 바뀌었습니다. 현재 PDF 적용과 새 PDF 저장은 전체 문서를 유지하면서 새 OCR 결과가 있는 선택 페이지만 교체합니다. 선택하지 않았거나 건너뛴 페이지, 새 글자를 찾지 못한 페이지의 기존 텍스트·주석·입력 양식·링크는 보존합니다. 아래의 주석·링크·입력 양식 제한은 실제로 OCR 결과를 반영해 교체한 페이지에만 해당합니다.

## 사용 흐름

- OCR 창 상단에 대상 PDF의 이름, 폴더, 페이지 수를 고정해서 표시한다.
- Apple Vision이 현재 Mac에서 지원하는 언어를 조회한다. 앱 언어와 각 언어의 원어 이름으로 검색하고 여러 언어를 선택할 수 있다. 선택한 언어를 목록 앞에 표시한다.
- 진행 중에는 언어·품질 설정을 잠그고 중단 버튼을 제공한다. 창을 닫아도 인식은 계속된다.
- 완료 후 `현재 PDF에 적용`과 `새 PDF로 저장…`을 제공한다. 완료 화면에 시작 안내를 표시하지 않는다. 언어·품질 설정을 바꾸면 새 설정으로 인식을 실행해야 한다.
- `현재 PDF에 적용`은 확인 안내 후 열린 문서에 실행 취소 가능한 편집을 만든다. 파일의 실제 변경은 일반 저장 흐름을 따른다.
- `새 PDF로 저장…`은 원본 폴더와 `원본이름-OCR.pdf`를 기본값으로 저장 창을 연다. 원본과 같은 경로나 링크로 덮어쓰는 것은 허용하지 않는다.

## 동작 경계

두 적용 방식은 기존 OCR 출력 방식을 사용하므로 주석 외형이 페이지에 합쳐지고 링크·입력 양식·댓글 기능을 유지하지 않는다. 현재 PDF에 적용하기 전 이 차이를 설명한다. 적용 전 페이지와 목차는 실행 취소에 보관하며, 기존 이력 정책에 따라 64페이지를 넘는 단일 작업도 가장 최근 작업으로 실행 취소할 수 있다.

완료한 모든 페이지가 있고 문서·설정·인식 결과가 일치할 때만 결과를 사용할 수 있다. 문서 편집, 실패한 재실행, 원본 파일 충돌은 오래된 결과가 적용되는 것을 막는다. 현재 문서에 적용하는 동안 결과 생성은 별도 작업에서 진행하고 저장과 중복 적용을 막는다. 암호화 문서의 기존 저장 제한은 유지한다.

선택 언어를 실제 인식 요청에 반영하며, 지원 언어가 하나도 없으면 임의로 영어를 사용하지 않는다. 이전 자동 언어 감지 결과가 재사용되지 않도록 설정 식별자를 갱신했다. PDF 만들기 화면의 기존 한·영·일 선택 UI는 이번 변경 범위에 포함하지 않는다.
