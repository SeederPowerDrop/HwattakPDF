# HwattakPDF 0.8.0 Developer Preview

HwattakPDF의 첫 공개 개발자 미리보기입니다. 구독과 광고 없이 Mac에서 PDF를 읽고, 정리하고, 공부하고, 간단히 편집할 수 있도록 만들었습니다.

이 버전은 완성된 정식판이 아닌 **Developer Preview**입니다. 중요한 문서는 먼저 복사본을 만들어 사용하고, 편집한 결과를 저장한 뒤 다른 PDF 뷰어에서도 확인해 주세요.

## 지원 환경

- macOS 14 Sonoma 이상
- Apple Silicon Mac 전용(`arm64`)
- 버전 0.8.0, build 18
- Intel Mac은 이번 공개 빌드에서 지원하지 않습니다.

## 주요 기능

- 1페이지, 연속 양면, 고정 양면 및 3~12페이지 개요를 포함한 다양한 PDF 보기 방식
- 여러 PDF를 탭·탭 스택·워크스페이스로 관리하고, 최대 4개 문서를 나란히 비교
- 하이라이트, 밑줄, 메모, 자유 텍스트, 펜 필기, 서명 및 이미지 추가
- 페이지 재정렬·회전·삭제·병합과 선택 페이지 PDF·PNG 추출
- 문서 검색, 최근 파일, 세션 복원 및 문서별 실행 취소·다시 실행
- Apple Vision을 이용한 한국어·영어·일본어 로컬 OCR과 검색 가능한 PDF 내보내기
- 사용자가 직접 API 키와 전송 범위를 확인하는 선택형 PDF AI 기능
- 권한을 먼저 검토하고 설치하는 번역·웹 브라우저 패널 플러그인
- YouTube 학습 manifest는 정책·동의 화면을 완성할 때까지 소스 전용 예제로 유지하며 이번 앱 번들에서는 제외
- 암호화 PDF의 복사·편집·추출 권한을 존중하는 보안 경계 강화
- 정보 및 후원 안내를 한국어·영어·프랑스어·독일어·스페인어·일본어·중국어 간체·아랍어·포르투갈어·베트남어로 제공

HwattakPDF에는 구독료와 광고가 없습니다. 자발적인 후원은 무료 개발과 유지보수를 계속할 수 있는 유일한 지원 수단입니다.

## 다운로드 무결성 확인

[공식 GitHub 저장소](https://github.com/SeederPowerDrop/HwattakPDF)의 0.8.0 릴리스에서 Apple Silicon용 ZIP을 받으세요. 다운로드한 파일의 SHA-256 값은 **릴리스 자산 옆 `.sha256` 파일을 확인**하고, 두 값이 정확히 일치할 때만 실행하세요.

터미널에서 다운로드한 ZIP의 값을 확인하려면 해당 파일이 있는 폴더에서 다음 명령을 실행할 수 있습니다.

```bash
shasum -a 256 HwattakPDF-0.8.0-macOS-arm64.zip
```

## 설치 및 실행

1. `HwattakPDF-0.8.0-macOS-arm64.zip`을 내려받고 `.sha256` 파일과 값을 비교합니다.
2. ZIP의 압축을 풉니다.
3. `HwattakPDF.app`을 `응용 프로그램` 폴더로 옮깁니다.
4. `응용 프로그램` 폴더에서 HwattakPDF를 실행합니다.

### 처음 실행할 때 경고가 표시되는 경우

이 Developer Preview는 **개발용 ad-hoc 서명**을 사용하며, Apple Developer ID 서명과 공증을 받지 않았습니다. 따라서 macOS가 개발자를 확인할 수 없거나 앱을 검사할 수 없다는 경고를 표시할 수 있습니다. 이는 Apple이 이 빌드를 검토하거나 악성 소프트웨어 여부를 공증했다는 의미가 아닙니다.

공식 GitHub 릴리스에서 내려받았고 `.sha256` 값이 일치하는 경우에만 다음 절차를 선택하세요.

1. HwattakPDF를 한 번 실행해 macOS 경고를 확인합니다.
2. `시스템 설정` > `개인정보 보호 및 보안`으로 이동합니다.
3. 보안 영역에서 HwattakPDF의 **그래도 열기**를 선택합니다.
4. 다시 표시되는 확인 창에서 앱을 열겠다는 의사를 확인합니다.

Apple은 확인되지 않은 앱의 보안 설정을 덮어쓰는 데 위험이 있을 수 있다고 안내합니다. 자세한 절차와 주의사항은 [Apple 공식 안내: 알 수 없는 개발자의 Mac 앱 열기](https://support.apple.com/ko-kr/guide/mac-help/mh40616/mac)를 확인하세요.

## 이번 빌드의 검증 결과

- 48개 테스트 클래스에서 총 641개 테스트 실행
- 실패 0건
- macOS 15의 알려진 PDFKit 테스트 환경 한계에 따른 예상 skip 2건
- Debug 및 Release 빌드, 앱 번들 구조, `arm64` 아키텍처, 지역화 리소스와 배포 ZIP 재개방 검증 완료

예상 skip은 사용자 기능 실패가 아니라 macOS 15에서 PDFKit UI 상태를 테스트 프로세스가 종료할 때 정리하는 과정의 알려진 환경 차이를 격리한 것입니다.

## 알아둘 점

- 인라인 텍스트와 시각적 텍스트 교체는 원문을 영구 삭제하는 보안 가림 기능이 아닙니다.
- OCR 내보내기는 보이는 페이지와 주석을 평탄화하므로 링크, 양식, 댓글 또는 기존 전자서명의 상호작용이 유지되지 않을 수 있습니다.
- AI 기능은 선택 사항이며, 사용자가 공급자 API 키와 전송 내용을 확인하고 승인한 요청에만 외부 서비스를 사용합니다.
- 기본 서명과 일부 앱 상태는 macOS Keychain 및 로컬 저장소를 사용하지만, 이번 ad-hoc 빌드는 정식 Developer ID 빌드와 동일한 장기 키체인 호환성을 보장하지 않습니다.
- 중요한 PDF는 원본을 보관하고 복사본에서 먼저 작업하세요.
