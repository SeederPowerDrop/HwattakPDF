# HwattakPDF 0.9.0 Developer Preview

**버전 0.9.0 · build 20 · 누적 소스 정리 2026-10-01**

0.8.0 공개 이후의 PDF 만들기·변환·복구와 파일 연결, 간결한 읽기 화면, OCR·번역 개선을 묶은 개발자 미리보기입니다. [9월 23일 소스 갱신](SOURCE-UPDATE-2026-09-23.md)에서 이름을 통일한 뒤의 누적 변경은 [10월 1일 소스 갱신](SOURCE-UPDATE-2026-10-01.md)에 정리했습니다. 이번 GitHub 작업은 소스 반영이며 새 바이너리 Release 공개는 포함하지 않습니다. 마지막 GitHub 다운로드 배포본은 0.8.0 (build 18)입니다.

## 지원 환경

- macOS 14 Sonoma 이상
- Apple Silicon Mac 전용(`arm64`)
- 개발용 ad-hoc 서명. Apple Developer ID 서명과 공증은 받지 않았습니다.

## 0.8.0 이후 달라진 점

### 파일 열기와 화면

- Finder에서 PDF를 더블클릭하거나 “다음으로 열기”로 실행했을 때 창과 문서가 열리지 않던 문제에 대응했습니다. 앱 준비 전에 받은 요청을 보관하고 창 표시 뒤 처리하며, 중복 파일 요청과 대기 중 창 닫기·재연결도 처리합니다. [이슈 #1](https://github.com/SeederPowerDrop/HwattakPDF/issues/1)과 [수정 제안 PR #2](https://github.com/SeederPowerDrop/HwattakPDF/pull/2)를 제공한 **mattkjeon**님께 감사드립니다. 현재 소스에는 독립적으로 구현한 앱 수명 기준의 조정기를 사용하며 PR을 병합한 것으로 기록하지 않습니다.
- 앱 표시 이름뿐 아니라 SwiftPM 패키지·실행 파일, 소스·테스트 디렉터리와 앱 타입 이름을 HwattakPDF로 통일했습니다. 기존 사용자 데이터와 PDF 주석을 읽는 내부 저장 식별자는 호환성을 위해 유지합니다.
- 설정에서 기본 PDF 앱 연결 상태를 확인하고 Finder의 연결 설정으로 이동할 수 있습니다. 앱의 남색·아이보리와 두 페이지 모양을 살린 PDF 전용 문서 아이콘을 추가했습니다.
- **설정(⌘,) → 화면 모드**, 또는 **보기 → 화면 모드**에서 라이트·다크·시스템 설정을 선택합니다. 선택은 다음 실행에도 유지되며 문서 작업공간과 보조 창에 함께 적용됩니다.
- 배경을 중립색으로 바꾸고 테두리·탭·도구줄의 무게를 줄였습니다. 홈은 **파일 열기와 최근 문서** 중심으로 정리했습니다. 한국어의 “PDF 비교”는 “PDF 같이 보기”로 표시합니다.
- 뷰어의 추가 도구는 필요할 때 펼치며, 편집·학습으로 전환하면 해당 도구가 나타납니다. 검색은 버튼이나 **⌘F**, 페이지 배치·맞춤은 보기 설정, 썸네일 묶음·크기는 페이지 패널의 작은 설정 메뉴에서 엽니다. 기능과 기존 메뉴·단축키 접근은 유지합니다.

### 읽기와 학습

- 메인 PDF에서 상하 스크롤 또는 좌우 넘김을 선택합니다. 좌우 넘김은 방향키·스와이프를 지원하며 여러 페이지 보기에서는 묶음 단위로 이동합니다.
- 보기 설정에서 **가로 폭 맞춤·세로 높이 맞춤**을 선택하고 문서별 선택을 복원합니다. 썸네일 패널에서도 방향키로 페이지를 탐색합니다.
- 페이지 패널을 넓히거나 높이면 썸네일도 함께 커집니다. 세로 패널의 폭과 가로 패널의 높이, 페이지 비율·회전을 반영하며 크기를 바꾸는 동안 기존 미리보기를 유지합니다. 1·2·4페이지 묶음 설정은 메인 PDF의 보기 방식과 별개입니다.
- 방향키를 길게 누를 때 기본 반복 속도를 이전보다 **1.8배**, **Shift+방향키**는 이전 기본 대비 **4배**로 높였습니다. **설정 → PDF 보기 조작 → 방향키 이동 속도**에서 느리게·보통·빠르게를 선택합니다. **Option+방향키**는 기존 페이지 넘김 등 PDFKit 동작을 유지하며, 글자 입력·선택이나 주석 이동을 가로채지 않습니다.
- 하이라이트와 밑줄의 굵기를 따로 기억하고, 밑줄이 작은 글자를 덮는 문제와 표식 적용 후 남는 선택 표시를 수정했습니다. 도구 안에서 색상을 고르는 팔레트도 추가했습니다.
- 잘못된 글꼴 치수 때문에 선택 표시가 페이지를 덮는 PDF는 원문을 유지한 임시 선택용 페이지에서 치수를 보정합니다. 일반 드래그로 한 페이지의 글자를 따라 선택하고, 선택한 원문을 번역·복사에 사용합니다. 원본 PDF는 바꾸지 않습니다. 보정할 수 없는 페이지는 사각형 문자 인식으로 전환하며, **Option(⌥)을 누른 채 드래그**하면 직접 영역을 지정할 수 있습니다. 문자 인식 결과에는 오타가 있을 수 있습니다.
- 클릭하여 열고 검색하는 플러그인 목록을 제공하며, 메뉴를 고르는 도중 하위 메뉴가 닫히는 문제를 수정했습니다.
- 페이지 번역에서 문단별 결과를 검토하고 내보낼 수 있습니다. Apple 번역·사용자 설정 AI와 별도로 **로컬 언어팩**을 선택할 수 있으며, Argos 도우미는 사용자가 직접 실행합니다. 최초 설치·언어팩 준비에는 인터넷이 필요하고, 준비된 언어팩의 번역은 이 Mac에서 처리합니다. [설치 방법과 한계](LOCAL-TRANSLATION.md).

### PDF 만들기와 변환

- OCR 대상을 전체 페이지, 현재 페이지, 직접 입력한 페이지 번호·범위 중에서 선택합니다. 예를 들어 `1, 3-5, 8`을 입력하면 해당 페이지만 인식하고 나머지 페이지는 유지합니다. 적용·새 PDF 저장 모두 전체 문서에서 선택한 페이지만 반영하며, OCR 설명을 쉬운 표현으로 바꿨습니다.
- 로컬 OCR에서 현재 Mac이 지원하는 언어를 검색·선택하고 대상 PDF 이름·폴더·페이지 수를 확인합니다. 완료 후 현재 PDF에 실행 취소 가능한 편집으로 적용하거나, 원본 폴더에 `원본이름-ocr.pdf`를 기본값으로 새 PDF를 저장할 수 있습니다. 현재 PDF에 적용한 내용은 저장할 때 파일에 반영됩니다.
- 저장 창에서 선택한 파일에만 쓰기 권한이 있을 때 OCR 사본 저장이 실패하던 문제를 수정했습니다. 긴 한글 파일명도 처리하며, 저장 실패 시 실제 원인과 다시 저장할 수 있다는 안내를 표시합니다.
- OCR은 기존 텍스트가 있는 페이지도 기본적으로 다시 인식합니다. 재인식한 페이지의 잘못된 옛 텍스트는 새 결과로 교체하고, 검색되지 않는 글자가 보일 때 재인식 방법을 안내합니다. 기존 텍스트를 교체하는 페이지는 선택한 해상도의 이미지와 새 검색용 텍스트로 저장합니다.
- 이미지를 탭에서 열고, 여러 이미지·로컬 HTML·기존 PDF의 선택 페이지와 공백 페이지를 조립해 새 PDF를 만듭니다.
- PDF 만들기의 안정성 우선·속도 우선 선택, 예상 시간·용량, 한·영·일 OCR과 검색 가능한 텍스트 층, 인식 텍스트 복사·파일 저장을 제공합니다.
- PDF 각 페이지의 보이는 모양을 이미지로 담아 Word(`.docx`)·PowerPoint(`.pptx`)로 내보냅니다. 한 페이지씩 처리하며 진행률과 취소를 지원합니다.
- 이미지의 최초 PDF 저장, 같은 이미지의 중복 탭, 조립 도중 바뀐 원본 파일 처리와 비정상 Office 페이지 크기 검사를 보완했습니다.

### 복구와 플러그인

- 비암호화 문서의 확정된 편집을 로컬 복구 사본으로 보관합니다. **PDF → 작업 복구…**에서 별도 문서로 열 수 있으며, 설정에서 복구와 OCR 체크포인트를 관리합니다.
- 지연 썸네일과 대용량 탭 처리, OCR 뒤 복구 예약, 휴면 복구 탭 닫기, PDF 복사·지우개 권한 검사를 개선했습니다.
- 필압에 따라 굵기가 변하는 획과 저장 외형을 지원하고, 필압 주석이 있는 페이지를 추출할 때 종료되던 문제를 수정했습니다.
- 문서 명령 플러그인(schema 3)과 **⇧⌘P** 명령 팔레트를 추가했습니다. 번역 도우미·웹 브라우저에 더해 Study Markup·Tablet Tools·Reading Navigation 검토본을 포함합니다. 각 플러그인은 권한을 확인한 뒤 설치하며 자동 활성화되지 않습니다.

## 설치와 업데이트

1. `HwattakPDF-0.9.0-macOS-arm64.zip`의 SHA-256 값을 함께 제공된 체크섬과 비교합니다.
2. 기존 앱을 사용 중이면 문서를 저장하고 HwattakPDF를 종료합니다.
3. 압축을 풀어 `HwattakPDF.app`을 응용 프로그램 폴더에 넣고 실행합니다.
4. 기본 PDF 앱으로 사용하려면 **설정 → 기본 PDF 앱 → Finder에서 연결 설정…**을 연 뒤 **정보 가져오기 → 다음으로 열기 → HwattakPDF → 모두 변경**으로 연결합니다.

터미널에서는 다음과 같이 ZIP의 SHA-256을 확인할 수 있습니다.

```bash
shasum -a 256 HwattakPDF-0.9.0-macOS-arm64.zip
```

이 빌드는 공증을 받지 않아 처음 실행할 때 macOS가 경고할 수 있습니다. 출처와 체크섬을 확인한 경우에만 앱을 한 번 열어 본 뒤 **시스템 설정 → 개인정보 보호 및 보안**의 실행 허용 절차를 선택하세요. 자세한 절차는 [Apple 공식 안내](https://support.apple.com/ko-kr/guide/mac-help/mh40616/mac)를 따릅니다.

## 검증과 알려진 한계

현재 누적 소스의 검증과 범위는 [10월 1일 소스 갱신 기록](SOURCE-UPDATE-2026-10-01.md)에 있습니다. 9월 22일 패키지의 결과·체크섬은 [0.9.0 배포 검증 기록](RELEASE-VALIDATION-0.9.0.md), 이름 통일 직후 검사는 [9월 23일 소스 갱신 기록](SOURCE-UPDATE-2026-09-23.md)을 따릅니다. 이전 검사 수와 체크섬을 새 빌드 결과로 사용하지 않습니다. 디자인 미리보기는 검증용 문서를 넣은 SwiftUI 화면 자료이며 실제 PDFKit 렌더링 검증과 구분합니다.

- **Office 변환:** 페이지 이미지 방식이며 원문의 문단·표·도형을 개별 객체로 편집하는 변환은 아닙니다. 실제 Office 앱과 버전별 시각 호환성의 수동 검증은 아직 완료되지 않았습니다.
- **HTML·이미지 입력:** HTML은 로컬 WebKit에서 처리하며 복잡한 레이아웃의 결과는 확인이 필요합니다. 로컬 스크립트가 실행될 수 있으므로 신뢰할 수 있는 HTML을 사용하세요. 애니메이션·다중 프레임 이미지는 전체 프레임을 페이지로 펼치지 않습니다.
- **복구·편집:** 자동 복구는 정상 저장을 대체하지 않으며 암호화 문서, 입력 중인 내용, 마지막 대기 시간 이후의 편집까지 보장하지 않습니다. 인라인 텍스트는 주석 기반으로 원문을 영구 삭제하는 보안 가림 기능이 아닙니다.
- **OCR·필기:** OCR 결과로 바꾸는 페이지는 주석 외관을 평탄화하므로 링크·양식·기존 전자서명 상호작용이 유지되지 않을 수 있습니다. 선택하지 않았거나 새 인식 결과가 없는 페이지는 보존합니다. 실제 iPad·Sidecar·Wacom 입력, macOS별 GUI와 File Provider, 장시간 실문서 사용은 자동 검사만으로 검증 완료를 주장하지 않습니다.
- **PDF 아이콘:** 시스템 등록과 실제 파일 아이콘 조회에서는 새 디자인을 확인했습니다. Finder 정보 창에 남은 이전 아이콘 캐시의 갱신은 아직 확인하지 못했습니다.
- **외부 서비스·플러그인:** AI는 사용자가 API 키와 전송 내용을 확인한 요청에만 외부 서비스를 사용합니다. YouTube 학습 예제는 소스 전용이며 이번 앱 번들에서 제외합니다. 임의 JavaScript 플러그인을 실행하는 런타임은 제공하지 않습니다.

중요한 원본은 보관하고, 편집·변환한 결과는 저장 후 확인해 주세요. 기능별 세부 범위는 [프로젝트 README](../README.md)와 [문서 지도](README.md)에서 볼 수 있습니다.
