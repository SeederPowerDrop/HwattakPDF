# HwattakPDF 0.9.0 배포 검증 기록

**0.9.0 (build 19) Developer Preview · 2026-09-22**

이번 기록은 **2026-09-22에 만든 로컬 패키지**의 고정 검증 기록입니다. 아래 검사 수·체크섬은 SwiftPM 이름 통일 전 패키지에 해당하며, [9월 23일 소스 갱신](SOURCE-UPDATE-2026-09-23.md)과 이후 재빌드의 결과로 재사용하지 않습니다. 이 패키지를 만들 당시 GitHub 업로드, 태그 생성과 Apple 공증은 포함하지 않았습니다. 기능과 설치 안내는 [릴리스 노트](RELEASE-NOTES-0.9.0.md)를 확인하세요.

## 검사 환경과 소스

- macOS 15.7.5 (24G624), Apple Silicon arm64
- Apple Swift 6.2.4, Swift 언어 모드 5
- 최소 지원 환경: macOS 14.0, arm64 전용
- 기준 Git 커밋: `a5343f5`에 이후 작업 트리 변경을 포함했습니다. 기준 커밋만으로 이번 앱을 재현할 수 없습니다.
- 실제 빌드에 사용한 수정 소스·테스트·자산·문서를 별도 `HwattakPDF-0.9.0-source.zip`으로 보존합니다. 스냅샷 안의 파일별 SHA-256 목록으로 내용을 식별하며 `.git`, 빌드 캐시, 작업 로그, 사용자 문서는 제외합니다.

## 전체 자동 검사

`scripts/run_test_batches.sh`는 등록된 65개 테스트 클래스와 실제 클래스 목록을 비교한 뒤 새 빌드 디렉터리에서 7개 독립 프로세스로 검사했습니다.

| 배치 | 검사 수 | 통과 | 조건부 제외 | 실패 |
| --- | ---: | ---: | ---: | ---: |
| presentation | 234 | 232 | 2 | 0 |
| image-interaction | 23 | 23 | 0 | 0 |
| native-form-interaction | 2 | 2 | 0 | 0 |
| document | 244 | 244 | 0 | 0 |
| workspace | 130 | 130 | 0 | 0 |
| assistant | 108 | 108 | 0 | 0 |
| plugins | 55 | 55 | 0 | 0 |
| **합계** | **796** | **794** | **2** | **0** |

두 조건부 제외는 기존 `PDFViewportScrollInteractionTests`의 네이티브 두 페이지 배치와 포인터 중심 확대 검사입니다. macOS 15 PDFKit이 화면 밖 타일을 해제하는 과정에서 XCTest를 종료하는 문제가 있어 해당 환경에서 제외합니다. 두 시나리오가 자동 검사로 검증됐다고 주장하지 않습니다.

처음 제한된 도구 환경에서 실행했을 때는 WebKit 보조 프로세스 시작이 차단되어 HTML 변환 관련 4건이 실패했습니다. macOS 보조 프로세스를 정상 실행할 수 있는 호스트 환경에서 전체 7개 배치를 다시 실행해 위 결과를 얻었습니다. 실패를 감추기 위해 제품 코드나 검사를 변경하지 않았습니다.

추가로 `zsh scripts/validate_plugin.sh --examples`를 실행해 현재 호스트 버전 `0.9.0`에서 커뮤니티 예제 5개가 모두 유효함을 확인했습니다. 이 추가 검사는 위 796건 합계에 중복 집계하지 않았습니다.

원본 로그는 로컬 작업 기록 `work/release-0.9.0-2026-09-22/tests-full-host.log`에 보존합니다. 로컬 경로가 포함된 원본 로그는 공개용 소스나 앱 ZIP에 넣지 않습니다.

## 패키지 검사

`scripts/validate_project.sh`와 `scripts/build_app.sh`가 성공했습니다. 릴리스 앱을 ZIP에서 다시 꺼내 다음을 확인했습니다.

- 버전 `0.9.0`, 빌드 `19`, `arm64`, 최소 macOS `14.0`
- 앱 코드 서명 검증과 샌드박스·사용자 선택 파일 읽기/쓰기·앱 범위 북마크·네트워크 클라이언트 권한 유지
- 10개 언어 리소스, 5개 기본 플러그인 검토본, 앱 아이콘 선택지와 라이선스·자산 고지 포함
- `HwattakPDFDocument.icns` 등록·원본 바이트 일치, 일반/Retina 10개 아이콘 표현 디코딩
- ZIP 루트의 `HwattakPDF.app`, `INSTALL-macOS.txt`, `RELEASE-NOTES-0.9.0.md` 3개 항목과 안내 문서 내용 일치
- ZIP CRC 정상, ZIP에 AppleDouble 파일이 없으며 실행 파일에 개인 빌드 경로가 포함되지 않음
- 빌드 시작 때 기록한 260개 소스·테스트·자산·예제 입력의 SHA-256이 빌드 후에도 동일함

독립적인 최종 패키지 점검도 26개 항목 모두 통과했습니다. ZIP에 사용자 PDF·작업 폴더·소스가 섞이지 않았고, 앱 실행 파일의 권한과 Mach-O 최소 OS도 확인했습니다. 점검용으로 추출한 임시 앱은 정리했습니다.

앱 ZIP: `HwattakPDF-0.9.0-macOS-arm64.zip`

```text
SHA-256 6e07d85b2a73699a20bd380b6f99e8235fefa8dbf3e7530c6c0b25afd27c6faa
```

소스 ZIP의 체크섬은 함께 제공한 `.zip.sha256`와 `SHA256SUMS.txt`를 따릅니다. 소스 ZIP 안의 검증 기록에 그 ZIP 자신의 해시를 넣으면 파일 내용이 다시 바뀌므로 외부 체크섬으로 관리합니다.

## 앞선 실제 화면 확인

다음은 2026-09-21에 같은 기능 코드로 수행한 설치 앱 확인입니다. 이번 버전 번호 변경 뒤에 모두 새로 수행한 검사는 아닙니다.

- Finder에서 테스트 PDF를 더블클릭해 앱 창과 문서가 함께 열리는 것을 확인했습니다. 기존 문서 탭도 복원됐습니다.
- 설정에서 라이트·다크를 전환해 실제 문서 창에 적용되는 것을 확인하고, 앱을 다시 실행했을 때 선택한 모드가 유지되는 것을 확인했습니다. 테스트 후 시스템 설정 모드로 되돌렸습니다.
- PDF 전용 아이콘의 시스템 등록과 실제 파일 아이콘 조회에서 새 디자인을 확인했습니다. Finder 정보 창에 남은 이전 아이콘 캐시의 갱신은 확인하지 못했습니다.
- 앞선 검증 기록은 로컬 `work/external-open-2026-09-21`, `work/appearance-2026-09-21`, `work/document-icon-2026-09-21`에 보존합니다. 사용자 작업공간이 담긴 화면과 세션 백업은 배포물에서 제외합니다.

## 남은 확인과 배포 범위

이 빌드는 Developer ID 인증서가 없는 개발용 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 다른 Mac에서 내려받아 처음 여는 Gatekeeper 흐름은 별도 확인이 필요합니다.

실제 Office 앱의 버전별 시각 호환성, macOS 14 및 다른 OS 버전의 전체 GUI, iPad·Sidecar·Wacom 필기, File Provider별 열기·저장, 장시간 대용량 실문서 사용은 이번 자동 검사만으로 완료를 주장하지 않습니다. Office 내보내기는 페이지 이미지 방식입니다. 기능별 추가 한계는 릴리스 노트를 따릅니다.
