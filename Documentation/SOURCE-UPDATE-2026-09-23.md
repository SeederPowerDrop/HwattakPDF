# HwattakPDF 이름 통일과 누적 소스 갱신 — 2026-09-23

공개 소스 기준 `a5343f5` 이후의 읽기·학습·파일 열기 개선과 **0.9.0 (build 19) Developer Preview** 준비 내용을 정리했다. 앱 표시 이름부터 SwiftPM·소스·테스트까지 **HwattakPDF**로 통일한다. 이번 GitHub 작업은 소스·테스트·자산·문서 반영이며, 새 태그나 바이너리 Release 자산 공개는 포함하지 않는다. GitHub Releases의 마지막 다운로드 배포본은 **0.8.0 (build 18)**이다.

## 제품 방향

- 구독·계정 없이 핵심 읽기·주석·페이지 편집·OCR을 Mac에서 처리한다. 공식 앱은 무료로 제공하며 자발적인 후원이 기능이나 지원 우선순위를 바꾸지 않는다.
- 여러 PDF를 탭·스택·워크스페이스와 같이 보기로 관리하고, 키보드·트랙패드로 오래 읽고 공부하기 편한 조작을 우선한다.
- 원본 보호, 저장 검증, 실행 취소와 작업 복구를 유지한다. 외부 AI는 사용자가 공급자와 전송 내용을 확인한 요청에만 사용한다.
- 플러그인은 권한을 확인한 선언형 작업과 앱 소유 패널·문서 명령을 제공한다. 임의의 패키지 코드를 실행하는 플러그인 런타임은 범위에 포함하지 않는다.
- 현재는 macOS에 집중한다. iPad 확장과 실제 PDF 본문 객체 편집은 향후 범위이며, 주석 편집·페이지 이미지형 Office 내보내기를 그 기능으로 표현하지 않는다.

상세한 구현·부분 구현·향후 범위는 [제품 정의](PRODUCT.md)와 [아키텍처](ARCHITECTURE.md)를 따른다.

## 이름과 기존 데이터 호환성

SwiftPM 패키지·실행 타깃·실행 파일을 `HwattakPDF`, 테스트 타깃을 `HwattakPDFTests`로 바꿨다. 소스는 `Sources/HwattakPDF`, 테스트는 `Tests/HwattakPDFTests`에 두며 앱 시작점·테마·관련 타입, 빌드 스크립트와 기여 안내도 같은 이름을 사용한다. 소스 실행 명령은 `swift run HwattakPDF`다.

기존 설치와 사용자 데이터를 새 앱으로 오인하거나 잃지 않도록 bundle ID `com.vibepdf.mac`, 기존 저장소·Keychain 식별자, OCR 기록의 과거 디렉터리와 PDF 주석의 legacy 접두사는 호환성 목적으로 유지한다. `com.vibepdf.` 플러그인 식별자 영역도 계속 예약하여 이전 호스트를 사칭하지 못하게 한다. 이 값들은 사용자에게 표시하는 앱 이름과 구분한다. 날짜가 붙은 감사·검증 문서의 옛 소스 경로·ZIP 이름·체크섬은 당시 증거를 보존한다.

## Finder 파일 열기 제보와 대응

**mattkjeon**님이 2026-09-22에 [이슈 #1](https://github.com/SeederPowerDrop/HwattakPDF/issues/1)과 [수정 제안 PR #2](https://github.com/SeederPowerDrop/HwattakPDF/pull/2)를 제공했다. 앱을 완전히 종료한 뒤 Finder의 “다음으로 열기”로 PDF를 열면 빈 창이 나타났다 사라지고 문서가 열리지 않는 증상과 시작 순서의 문제를 설명했다. 제보와 재현·수정 제안에 감사드린다.

현재 소스는 이미 로컬에서 진행한 `AppExternalFileOpenCoordinator` 기반 수정을 사용한다. 앱이 준비되기 전에 들어온 URL과 샌드박스 접근 수명을 앱 수준에서 보관하고, 주 창을 표시한 다음 파일을 탭으로 연다. 같은 순간 들어온 파일 요청을 모아 중복을 제거하며, 창 콜백의 재연결이나 요청 대기 중 창 닫기 때문에 요청이 사라지지 않게 한다. 실행 중 새로운 요청과 같은 파일을 나중에 다시 여는 흐름도 처리한다.

이는 같은 시작 순서 문제에 대한 독립적인 구현이며, **PR #2를 병합했다는 기록은 아니다**. 자동 회귀 검사는 창 준비 전 요청, 여러 파일·중복 전달, 창 재연결·닫기, 외부 웹 URL 제외와 타이머 이후 재열기를 다룬다. 실제 Finder 열기의 앞선 수동 확인과 이번 검증은 아래 기록에서 날짜를 구분한다.

## 0.9.0에 포함한 누적 변경

- **읽기·화면:** 라이트·다크·시스템 화면 모드, PDF 문서 아이콘, 기본 PDF 앱 연결 안내, 정리된 툴바·탭 막대, 상하 스크롤·좌우 넘김, 방향키·스와이프와 페이지 묶음 이동, 가로 폭·세로 높이 맞춤과 문서별 복원.
- **학습·플러그인:** 하이라이트·밑줄별 굵기 기억, 작은 글자를 덮는 밑줄과 남은 선택 표시 수정, 도구 안의 색상 팔레트, 검색 가능한 플러그인 목록, schema 3 문서 명령과 명령 팔레트.
- **PDF 만들기·변환:** 이미지·로컬 HTML·선택 PDF 페이지·공백 조립, 안정성·속도 선택과 OCR, Word·PowerPoint 페이지 이미지 내보내기. 이미지 최초 저장·중복 탭·변경된 원본과 비정상 Office 페이지 크기를 검사한다.
- **안정성·복구:** 대용량 문서·지연 썸네일·탭 휴면, 비암호화 문서의 작업 복구, OCR 후 복구 예약과 휴면 복구 탭 닫기 수정. 필압 주석 페이지 추출 시 종료, PDF 복사 권한과 읽기 전용 지우개 처리를 수정했다.
- **개발·기여:** 앱·코드 이름 통일, 10개 언어 문구, 회귀 검사와 플러그인 제작·검증 안내, 날짜별 감사·수정 근거를 함께 유지한다.

자세한 사용자 변경과 한계는 [0.9.0 릴리스 노트](RELEASE-NOTES-0.9.0.md)를 따른다. 앞선 수정의 세부 근거는 [9월 5일 안정화](STABILIZATION-2026-09-05.md), [9월 9일 버그 수정](STABILIZATION-2026-09-09.md), [9월 13일 소스 갱신](SOURCE-UPDATE-2026-09-13.md)에 있다.
