## 검증 결과

검증 환경은 Apple Silicon, macOS 15.7.5 (24G624)다. 합성 PDF·이미지와 테스트용 클립보드/URL 콜백을 사용했으며 사용자 문서를 수정하거나 외부 서비스에 전송하지 않았다.

- 추가 회귀 36건 통과. 필기 추출은 실제 PDF 저장·재개방·픽셀 검사를 포함하며, 복사본을 저장할 때 발생했던 강제 종료가 재발하지 않았다.
- 전체 회귀: 58개 클래스·7개 격리 배치, **721건 중 719 통과·기존 조건부 제외 2·실패 0**. 제외된 2건은 macOS 15 PDFKit 오프스크린 타일 수명 문제로 기존부터 제외한 펼침/포인터 중심 확대 검사다.
- 대용량 합성 회귀: 1,000페이지 문서 20개 탭의 초기 resident 문서 1개, 설치 약 0.192초. 약 63MB 스캔 PDF 열기 약 0.011초, 마지막 페이지 렌더링 성공. 이번 1회 모델 측정이며 실제 GUI 장시간 사용 성능으로 확대 해석하지 않는다.
- Release 빌드, ad-hoc 코드 서명, ZIP 재추출 후 리소스·entitlement·arm64 검증 통과.

## 호환성과 남은 확인

- Office 용지/슬라이드 범위를 넘는 페이지를 자동으로 축소하지 않는다. 지원하지 않는 크기는 페이지 오류로 안내한다. 정상적인 회전·혼합 크기는 기존과 같이 첫 페이지 캔버스에 비율을 유지해 배치한다. Word 용지의 최대 31,680 twips는 [Microsoft 문서](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/e7017520-06b4-438f-97d2-3e49f247ca9f), PowerPoint 좌표 범위는 [공식 Open XML SDK 검증 테스트](https://github.com/dotnet/Open-XML-SDK/blob/main/test/DocumentFormat.OpenXml.Tests/ofapiTest/OpenXmlValidatorTest.cs)에 근거한다.
- 플러그인 schema와 설치 형식은 바뀌지 않는다. PDF가 허용하지 않는 텍스트 추출을 거부하며, 정적 도움말과 문서명·페이지 번호 같은 메타데이터 기능은 유지한다.
- 복구 기능은 기존의 비암호화 문서 대상·편집 후 5초/대형 문서 60초 대기·용량 제한을 유지한다. 이번 수정은 OCR 종료/세션 수명 중 예약과 닫기 상태가 빠지는 문제를 다룬다.
- 실제 iPad/Sidecar/Wacom 입력, macOS 14·26, iCloud/File Provider·파일 단위 sandbox 저장 권한, 장시간 대형 실문서 GUI 사용은 이번 자동 검사로 검증 완료를 주장하지 않는다. 이 6건의 수정 완료와 모든 환경에서의 무결함 보장은 구분한다.
