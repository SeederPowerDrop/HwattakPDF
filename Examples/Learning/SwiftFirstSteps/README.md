# Swift 첫걸음: 글자로 확인하는 페이지 이동

이 실습은 [2장. 우리 앱을 읽기 위한 Swift 기초](../../../Documentation/Learning/02-SWIFT.md)의 첫 번째 실습입니다. 코드를 처음 읽는다면 [0장. 코드를 처음 읽는 사람을 위한 준비](../../../Documentation/Learning/00-FIRST-STEPS.md)부터 읽어 보세요.

실제 앱에는 창과 버튼, PDF 문서가 함께 있습니다. 여기서는 페이지 이동의 기본 규칙만 [main.swift](main.swift) 한 파일에 담았습니다. 화면 대신 `print`로 실행 결과를 보여 줍니다. 이 예제를 실행하거나 수정해도 실제 앱의 코드, PDF 파일, 앱 설정은 바뀌지 않습니다.

## 1. 먼저 실행해 보세요

Swift 도구가 설치된 Mac에서 터미널(Terminal)을 열고, 이 프로젝트의 최상위 폴더로 이동해 주세요. `Package.swift`, `Sources`, `Examples`가 보이는 폴더입니다. 터미널 사용이 처음이라면 0장의 실행 준비 안내를 먼저 따라 해 보세요.

프로젝트 폴더에서 다음 한 줄을 입력하고 Return 키를 누르세요.

```sh
swift Examples/Learning/SwiftFirstSteps/main.swift
```

Swift는 파일을 읽고 위에서 아래로 실행합니다. `func`로 정의한 함수의 본문은 정의를 읽는 순간이 아니라 그 함수를 호출(call)했을 때 실행됩니다. 아무것도 수정하지 않았다면 다음 다섯 줄이 나옵니다.

```text
전체: 5페이지
시작: 1페이지
이동 후: 2페이지
이동 거절: 6페이지는 없습니다.
마지막 위치: 2페이지
```

첫 번째 이동은 성공하고, 두 번째 이동은 범위를 벗어나 거절됩니다. 그래서 마지막 위치는 2페이지입니다. 6페이지 이동이 거절되어도 프로그램은 계속 실행되어 마지막 위치를 출력합니다.

`swift`를 찾을 수 없다는 오류가 나오면 Swift 실행 도구가 준비되지 않은 상태입니다. 파일을 찾을 수 없다는 오류가 나오면 터미널의 현재 폴더와 입력한 경로부터 확인해 보세요.

## 2. 다섯 가지 문법만 찾아보세요

| 코드 | 이번에 알아볼 뜻 |
|---|---|
| `let pageCount = pageTitles.count` | 배열(array)에 들어 있는 값의 개수를 구해, 다시 대입하지 않을 이름에 저장합니다. |
| `var currentPageIndex = 0` | 현재 위치를 변수(variable)에 저장합니다. 인덱스(index) 0은 첫 페이지입니다. |
| `func displayPageNumber(for index: Int) -> Int` | 정수 하나를 받아 정수 하나를 돌려주는 함수(function)를 정의합니다. |
| `if pageNumber < 1 \|\| pageNumber > pageCount` | 번호가 1보다 작거나 전체 페이지 수보다 크면 거절합니다. `\|\|`는 “또는”입니다. |
| `currentPageIndex = pageNumber - 1` | 검사를 통과한 페이지 번호를 0부터 시작하는 인덱스로 바꿔 저장합니다. |

`print("전체: \(pageCount)페이지")`에서 `\(pageCount)`는 변수의 값을 문장에 끼워 넣습니다. 이를 문자열 보간(string interpolation)이라고 합니다. `pageTitles[currentPageIndex]`는 배열에서 그 인덱스에 있는 값을 가져옵니다. 범위 검사보다 먼저 이 부분을 실행하면 잘못된 인덱스로 배열을 읽을 수 있으므로, 이 예제에서는 먼저 번호를 검사합니다.

실제 앱의 `setCurrentPage`는 이미 0부터 시작하는 인덱스를 받습니다. 이 입문 예제의 `moveToPage`는 사람이 읽는 1부터 시작하는 번호를 받습니다. 두 함수의 입력 기준이 다르므로, 여기서는 1을 빼는 계산이 필요합니다.

## 3. 숫자 하나를 바꾸고 결과를 예상해 보세요

1. `main.swift`를 열고 맨 아래의 `moveToPage(2)`만 `moveToPage(3)`으로 바꿉니다.
2. 파일을 저장합니다. 저장하지 않은 편집 내용은 다음 실행에 반영되지 않습니다.
3. 같은 명령을 다시 실행하기 전에 마지막 위치가 무엇일지 적어 봅니다.
4. 다시 실행해 결과를 비교합니다. “이동 후”와 “마지막 위치”가 모두 3페이지로 바뀌어야 합니다. 6페이지 이동은 여전히 거절됩니다.
5. 실습을 마치면 `moveToPage(3)`을 `moveToPage(2)`로 되돌리고 저장합니다. 다시 실행하면 처음의 다섯 줄이 나옵니다.

각 실행은 처음부터 시작하므로, 지난번에 이동한 위치를 기억하지 않습니다. 프로그램이 값을 파일에 따로 저장하지 않았기 때문입니다. 다음으로 2장의 실제 `setCurrentPage`를 읽으며 “입력 → 검사 → 현재 위치 변경”이라는 같은 순서를 찾아보세요.
