# Markdown Quote

PDF에서 선택한 문장을 Markdown 인용문으로 미리 보거나 클립보드에 복사하는
HwattakPDF 선언형 플러그인 예시다.

## 사용법

1. HwattakPDF의 `플러그인 > 플러그인 관리…`에서 이
   `MarkdownQuote.hwattakplugin` 디렉터리를 설치한다.
2. PDF에서 문장을 선택한다.
3. `플러그인 > Markdown Quote`에서 미리보기 또는 복사 액션을 실행한다.

결과에는 선택 문장과 PDF 표시 이름, 현재 페이지, 전체 페이지 수가 들어간다.
요청 권한은 문서 metadata 읽기, 선택 텍스트 읽기, 클립보드 쓰기다.
