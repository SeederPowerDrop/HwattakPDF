# Reading Navigation

Navigate long PDFs and switch reading modes.

Install from the app’s reviewed bundled plugins. Commands use schema 3 host APIs, never package code. Annotations use the document Undo history. Pen and eraser require Editing or Study mode.

To create your own package, copy this directory, change the identifier to your own reverse-domain namespace (not `dev.hwattakpdf.*`), and edit the commands. See Documentation/PLUGINS.md.
