# Reference Search

PDF에서 선택한 문장을 Wikipedia 또는 Google Scholar에서 검색하는 HwattakPDF
선언형 플러그인 예시다.

## 사용법

1. HwattakPDF의 `플러그인 > 플러그인 관리…`에서 이
   `ReferenceSearch.hwattakplugin` 디렉터리를 설치한다.
2. PDF에서 검색할 문장을 선택한다.
3. `플러그인 > Reference Search`에서 검색 대상을 고른다.
4. HwattakPDF가 보여 주는 대상 호스트와 전송 정보 종류를 확인한 뒤 링크 열기를
   승인한다.

플러그인은 직접 네트워크 요청을 하지 않는다. 선택 텍스트는 URL 인코딩되며 사용자가
매 실행을 승인한 경우에만 기본 브라우저로 전달된다.
