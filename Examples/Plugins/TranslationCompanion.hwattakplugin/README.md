# 번역 도우미

PDF에서 문장을 선택한 뒤 `선택 문장 번역`을 실행하거나, `현재 페이지 번역`을
실행합니다. 보내기 전 텍스트와 서비스·대상 언어를 다시 확인할 수 있습니다.

- Google 번역: 확인한 짧은 텍스트를 HTTPS 번역 주소로 보냅니다.
- ChatGPT / Claude: 번역 프롬프트를 클립보드에 복사하고 임시 웹 세션을 엽니다.
  입력창에 붙여넣고 직접 보내야 전송됩니다.
- Google 번역 주소 한도를 넘는 긴 페이지는 ChatGPT 또는 Claude를 사용합니다.
- 스캔 페이지에 텍스트가 없으면 먼저 OCR을 실행합니다.

웹 세션은 패널을 닫으면 폐기되며, 각 서비스의 계정과 개인정보 처리방침이 적용됩니다.
