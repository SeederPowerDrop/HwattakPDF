# 번역 도우미

PDF의 보기·학습 모드에서 문장을 선택한 뒤 `선택 문장 번역`을 실행하거나,
`현재 페이지 번역`을 실행합니다. `앱에서 번역`에서 엔진과 언어를 고르고 원문을
확인합니다. 원문과 번역문을 문단별로 비교하고 번역본을 PDF·HTML로 저장할 수 있습니다.

- **macOS 번역**: macOS 15 이상에서 Apple Translation으로 앱 안에서 번역합니다.
  필요한 언어 다운로드는 macOS가 안내합니다. macOS 14.4에서는 시스템 번역 팝업을
  사용할 수 있지만 앱 안의 문단별 결과·내보내기는 제공하지 않습니다.
- **외부 AI**: 앱의 AI 설정에 등록한 공급자·모델·Keychain API 키를 사용합니다.
  전송할 원문과 공급자를 확인한 뒤 번역하며 웹 검색·MCP 도구는 사용하지 않습니다.
- **로컬 언어팩**: 이 Mac의 Argos Translate 도우미에 연결합니다. 공개 언어팩 목록을
  불러와 설치하거나 `.argosmodel`을 가져올 수 있습니다. 원문 언어를 직접 선택합니다.
  도우미 설치·실행은 저장소의 `Documentation/LOCAL-TRANSLATION.md`를 참고하세요.
  번역 중 네트워크 접속은 차단하며, 목록 갱신과 언어팩 다운로드만 인터넷을 사용합니다.

PDF 내보내기는 텍스트를 읽기 좋게 **다시 조판한 별도 문서**입니다. 원본 PDF의 그림,
표 셀, 글꼴과 좌표를 그대로 복제하지 않으며 원본을 수정하지 않습니다. 긴 문단은
번역 크기에 맞게 나뉠 수 있습니다. 페이지당 입력 한도는 16,000자·UTF-8 64 KiB입니다.
한도를 넘거나 일부 문단이 누락되면 실패를 표시하며, 완성된 번역으로 저장하지 않습니다.

`웹 번역 도우미`에서는 기존 서비스도 사용할 수 있습니다.

- Google 번역: 확인한 짧은 텍스트를 HTTPS 번역 주소로 보냅니다.
- ChatGPT / Claude: 번역 프롬프트를 클립보드에 복사하고 임시 웹 세션을 엽니다.
  입력창에 붙여넣고 직접 보내야 전송됩니다.
- Google 번역 주소 한도를 넘는 긴 페이지는 ChatGPT 또는 Claude를 사용합니다.
- 스캔 페이지에 텍스트가 없으면 먼저 OCR을 실행합니다.

웹 세션은 패널을 닫으면 폐기되며, 각 서비스의 계정과 개인정보 처리방침이 적용됩니다.
